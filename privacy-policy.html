Privacy Policy for ClickDeck

Overview

ClickDeck is a browser extension that allows users to visually select, edit, refine, and export HTML elements on the current page. This privacy policy explains how the extension handles user data.

Data Collection

Ordinary editing and export run locally. Optional cloud collaboration sends the information needed for the collaboration actions you explicitly request.

Creating a project requires Google sign-in. Google and Supabase process the basic account identity authorized during sign-in, which may include an account identifier, email address, name and profile image. ClickDeck does not receive your Google password or request access to Gmail, Drive or Calendar. Invited collaborators do not need Google sign-in; they receive a service-managed guest identity.

Creating or joining a project sends its name or invitation, a page fingerprint, a display name and the relevant account or guest identity to the configured collaboration service. Submitting selected changes sends structured proposals, which can include page text excerpts, before/after values, target locations and resource references. Other authorized project members can read shared proposals, their author display names and membership information; Google profile information is not used as the shared proposal author profile. Reviewing or refreshing a joined project contacts the service; local edits are not automatically submitted.

ClickDeck does not automatically upload the complete HTML document or page screenshots. Do not share sensitive content in a proposal unless you intend project members and the collaboration provider to receive it.

Data Storage

The extension uses chrome.storage for preferences, saved local edits and project associations. Collaboration credentials and saved invitations are stored in extension-origin IndexedDB; temporary login state and guest-session recovery data may use extension session storage. Authentication credentials are sent to the configured authentication/collaboration service as needed, not included in exported HTML or proposal text. Clearing extension data or uninstalling can remove a guest identity, which is not guaranteed to be recoverable. A local project-history entry is not a cloud backup.

Hosted collaboration projects expire 48 hours after creation; joining or submitting does not extend that deadline. Access ends at expiry, and scheduled cleanup removes expired project records and related proposals. Physical deletion may occur after the deadline. Exported files and local records are separate and are not deleted by cloud cleanup.

The project deadline is not an account or login-session deletion deadline. Google-linked accounts and provider operational records may remain after a project expires. Anonymous accounts are subject to separate cleanup rules. Contact the maintainer for account-data requests; do not post credentials, invitations or private page content in a public issue.

Third-Party Services

Configured cloud collaboration uses Supabase for authentication and database services. The provider receives collaboration requests and connection metadata needed to deliver and secure the service, such as IP addresses. The installed build contains public service connection configuration, not administrator credentials. Source builds without collaboration configuration remain usable for local editing.

ClickDeck does not automatically send page content to an AI service. Copying a prompt to the clipboard is a local action; if you paste it into another service, that service's own policies apply. Local diagnostic logs are copied only when requested; review them before sharing publicly.

Sharing and choices

Share invitation codes only with intended collaborators. Selecting or deselecting an unsubmitted proposal does not withdraw an earlier cloud submission. Stop using collaboration to stop future requests, and export information you need before expiry. Local removal of a project-history entry does not delete its cloud project. This policy describes extension behavior; it does not guarantee that a third-party provider immediately erases its operational logs.

Permissions

The extension currently requests the following browser permissions:

  • activeTab — to access the current page when the user activates the extension
  • scripting — to inject the editor UI into the active page
  • storage — to save preferences, local edits and collaboration sessions locally
  • identity — to open the user-requested Google authorization flow and receive its callback through the browser

ClickDeck also declares host access so it can run on pages the user chooses to edit and contact the configured collaboration service. These permissions support the local editor and optional collaboration described above, not advertising or cross-site activity tracking.
